# Отчёт о потерях перекладки

Не признание в плохой работе, а результат: показывает, что в старом фонде держалось на памяти собиравшего, а не на записанном, и что переложить полностью не удалось.

Состояние на конец захода: **переложено 24 источника** в `sources/` (гейт зелёный, кроме одного намеренно-красного — см. ниже), 3 файла пробелов в `gaps/`, перепись и выводы сданы. Темы, не тронутые этим заходом, перечислены в конце.

---

## 1. Записи со `статус: не установлен` — требуют НАСТОЯЩЕЙ проверки

Это НЕ «устарело», а «не проверено». Карточки издателя блокируют машинный запрос (HTTP 403), рабочих зеркал не найдено. Каждой нужна ручная сверка статуса по платному/архивному доступу.

| источник | файл | почему не установлен |
|---|---|---|
| ISO 81346-12:2018 | `sources/iso-81346-12-2018.md` | iso.org/standard/63886.html — HTTP 403; зеркал нет |
| IEC 81346-2:2019 | `sources/iec-81346-2-2019.md` | iso.org 403; № публикации webstore.iec.ch не подобран; дистрибьюторы блокируют |
| ISO 12006-2:2015 | `sources/iso-12006-2-2015.md` | iso.org 403; комитетская страница TC 59/SC 13 недоступна; BSI результата не дал |
| ISO 16739-1 / IFC 4.3 | `sources/iso-16739-1-ifc-4-3.md` | карточка ISO 16739-1 и buildingSMART — 403 везде; сама документация IFC открыта и читана первично |
| GS1 General Specifications | `sources/gs1-general-specifications.md` | номер текущей редакции (Release NN) не установлен: полный PDF на gs1.org — 403, на gs1ca.org превышает лимит выгрузки |

## 2. Записи с пустой `редакция` — гейт красный намеренно (правило 2 задания)

| источник | файл | что не так |
|---|---|---|
| GS1 General Specifications | `sources/gs1-general-specifications.md` | номер редакции General Specifications не установлен, поле оставлено пустым — гейт краснеет, и так и должно быть: без редакции неизвестно, что именно выписано. **Это единственный `✗` в финальном прогоне гейта.** |

Заполнять правдоподобным нельзя (правила 1–2 задания). Закрывается настоящей сверкой: достать полный текст General Specifications и зафиксировать точный Release NN + год той редакции, из которой сняты определения ключей.

## 3. Переложенные записи с неполными цитатами (вынести на сверку цитат)

Форму соблюдают, гейт проходят, но цитаты не первичны — нужна отдельная работа по сверке с действующим текстом.

- **`цитаты: вторичный`** (несущее — из пересказа/сторонней копии, каждая цитата помечена `[вторичный]`):
  - `sources/gs1-general-specifications.md` — все определения с обзорных страниц GS1, без номеров разделов;
  - `sources/iso-8015-2011.md` — несущие принципы 5.5/5.10 из training-источника (тело в открытое превью не вошло);
  - `sources/iec-61360.md` — актуальные атрибуты по IDTA-01003-a; первично только заменённая редакция 1998;
  - `sources/persistent-identifiers-handle-doi-ark.md` — DOI по инфраструктурным материалам, не по ISO 26324;
  - `sources/icc-incoterms-2020.md` — Explanatory Notes for Users (CPT/CIF/EXW/DDP) из сторонней копии платной публикации 723E; Introduction — открытый официальный текст.
- **`цитаты: предпросмотр`** (официальный открытый фрагмент издателя, платный текст целиком не получен): `iso-81346-12-2018`, `iec-81346-1-2022`, `iec-81346-2-2019`, `iso-12006-2-2015`, `iso-22095-2020`, `iso-55000-2024`, `iso-iec-11179-5-2005`, `apics-scor-v12`, `ascm-scor-ds`.

## 5. Раздел «Чего НЕ покрывает» — восстановлен у всех переложенных

У всех 24 переложенных записей раздел `## Чего НЕ покрывает` присутствовал в старом материале и перенесён дословно; сочинять не пришлось. Ненайденных границ, требующих пометки «раздел при перекладке не восстановлен», среди сданных нет.

## 6. Темы, НЕ тронутые этим заходом — переложить отдельно

Материал в старом фонде есть, форму он местами уже имеет (особенно в `handoff/`), но при данном заходе не переложен. Перечислено по переписи (`migration-source-census.md`).

- **Прослеживаемость и отгрузка** (`extracts/03`, `extracts/08`, `handoff/04`): GS1 EPCIS 2.0, GS1 CBV 2.0, **MIL-HDBK-61A (заменён MIL-HDBK-61B, 2020 — за 6 лет до выписки; ключевой пример задания)**, EBOM/MBOM/Service BOM, ISO 10303-1057 / STEP AP242, ГОСТ Р 2.106-2019, IEC 62890:2020, SPDX, CycloneDX/ECMA-424, SLSA, in-toto, «обязательство вести выпущенное» (CRA/GPSR/npm).
- **Аварийное поведение** (`extracts/04`, `extracts/09`, `handoff/07`): ~19 записей — IEC 61508, ISO 26262, аварийный останов (ISO 13850 / IEC 60204-1 — ревизия закрыла их статус «действует»), плюс концептные (fail-safe/secure, fail open/closed, fail-passive/operational, graceful degradation, fail-fast, shear pin, torque limiter, rupture disc, crumple zone, sacrificial anode, strong/weak link, fuse vs breaker, Circuit Breaker/Bulkhead, откат против компенсации).
- **Онтологии** (`extracts/05`, `handoff/05`): BFO / ISO/IEC 21838-2:2021 (ревизия: открытый артефакт bfo-2020-terms обновлён после публикации стандарта — release-2024-01-29), UFO / OntoUML, фасетная классификация (Ранганатан/PMEST), competency questions.
- **Метамодели / отношения** (`extracts/06`, `handoff/06`): DDD context map, **ArchiMate 3.1 (заменён дважды: 3.2 → ArchiMate 4)**, Backstage Software Catalog, ISA-88 / IEC 61512.
- **Поток-возвраты** (`extracts/07`, `handoff/03`): отзыв против изъятия (EU 178/2002, GPSR), RMA, прекращение выпуска (PCN/PDN, JESD48→J-STD-048A), сверка трёх документов (3-way match); **сквозной путь товара — это СВЕДЕНИЕ (собран из 8 сводов) → должен уехать в `digests/` с разделом «Происхождение», не в sources/**.
- **Ведение стандартов** (`handoff/01` + `raw/standards-process.md`): ~25 источников — RFC 2026/6410/7282/8126/8179/8594, W3C Process, **OASIS TC Process (заменён: 2017-05-26 → ред. 22.07.2020)**, CNCF Lifecycle, Apache Incubator, TC39, ANSI Essential Requirements (есть новее — январь 2025), Khronos, PEP 1, Rust RFC, Diátaxis, Kubernetes Deprecation Policy, SemVer, MADR, плюс по пересказу: Web Platform Tests, WHATWG, ECMAScript, C++ TS, Rust editions, «ISO: отдельная стадия».
- **Устройство производства** (`handoff/02` + `raw/pera-and-regulation.md`): PERA, уровни Purdue / IEC 62264-1:2013, ISA-95 (по пересказу), **ISO 9001:2015 (на пороге замены: FDIS, баллот закрыт 09.07.2026)**, GMP (EudraLex Annex 1/15, 21 CFR Part 211), квалификация DQ/IQ/OQ/PQ, безопасность машин (Regulation (EU) 2023/1230, по пересказу).

## 7. Записи «по пересказу» из старого фонда (шесть) — цитаты вторичны или отсутствуют

Собраны до того, как форма устоялась; при перекладке этих тем каждой присвоить `цитаты: вторичный` или `нет` и не выдавать пересказ за дословную норму: «ISO: отдельная стадия против правки после согласования»; «Web Platform Tests: табло вместо разовой отметки»; «ECMAScript: годовая отсечка по календарю»; «C++: обкатываемое публикуется отдельно от нормы»; «ISA-95: три разные иерархии»; «Безопасность машин: обязанность на изготовителе, а не на пользователе».

## 8. Ревизии — разнесены частично

Находки `revisions/2026-08-05-iso-iec.md` и `revisions/2026-08-05-industry.md`, относящиеся к переложенным источникам, внесены в их `## Журнал сверок`. Находки, относящиеся к НЕ переложенным темам (RFC/OASIS/ANSI/W3C из `revisions/2026-08-05-process-docs.md`; ISO 9001, EudraLex, IEC 62264, машины из iso-iec; GS1 EPCIS, MIL-HDBK-61A, ArchiMate, SLSA/in-toto/SPDX/CycloneDX, JEDEC из industry), ждут перекладки своих источников. Сами файлы ревизий по заданию должны после разноса уехать в `gaps/` как след партийной проверки — при данном заходе разнесены только по сданным источникам, поэтому исходные файлы ревизий пока не перемещены.
