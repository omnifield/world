# sources — выписки, по одной на источник

**Результат сбора.** Здесь лежит то, что решил рынок: один источник — один файл, форма — `../template/FORM.md`, бланк — `../template/_blank.md`.

## Два правила, на которых держится папка

**Единица хранения — источник, а не заход сбора.** Имя файла от обозначения (`iso-81346-12-2018.md`), не от порядкового номера партии. Раскладка по заходам размазывает одну норму по нескольким файлам, и обновить редакцию становится негде: прошлый фонд держал ISO 81346-12 в пяти местах сразу.

**Только чужое.** Выписка отвечает, что решил рынок, и молчит о том, что из этого следует нам. Наши выводы и ссылки на наши узлы гейт режет — не из строгости, а потому что фонд с примесью наших решений годен только нам и только сегодня.

## Файлы не в форме

`README.md` и всё, что начинается с `_`, гейт пропускает: это пояснения и бланки, а не выписки.
