# digests — сведения нескольких источников

**Здесь НЕ цитаты.** В `sources/` лежит по одному источнику на файл; сюда попадает то, что видно только при взгляде на несколько сразу: сквозной путь, сопоставление ответов, повтор, который ни в одном источнике не назван.

## Обязательное правило

Каждое сведение несёт раздел **`## Происхождение`** или явную **оговорку о происхождении**: из каких источников собрано, где ячейка заполнена по источнику, а где источника нет. Гейт (`tools/lint.mjs`) файл без этого режет.

Причина простая: сведение выглядит как знание, а является сборкой. Читатель, не видящий швов, примет нашу склейку за чужую норму.

## Чем заполняется пустая ячейка

**Словами «не покрыто», и ничем иным.** Не аналогией, не соседним источником, не разумным предположением. Ячейка, заполненная по аналогии, неотличима от заполненной по источнику — и через месяц отличить их будет уже некому.

## Что сюда не кладут

Наши выводы и решения. Правило «только чужое» действует и здесь: сведение показывает, как отвечают источники **вместе**, а не что нам из этого делать.
