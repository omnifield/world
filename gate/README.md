# gate — шлюз между ресурсами

**Зона заведена 2026-08-14. Наполняет её `owner-gate`; здесь только шапка, поставленная вместе с объявлением зоны.**

## Что это

Средство, которым **ресурсы связываются между собой**, чтобы юзеру не было между ними расстояния. В мире расстояний нет (`WORLD2` 5.3), а в железе они есть — этот разрыв закрывает шлюз.

**Мир такого не изготавливает** (`WORLD2` 0.1: мир не изготовитель, инструменты приносит юзер), поэтому шлюз — обычный инструмент, и делаем его мы. Здесь он лежит **временно и сознательно**: чтобы потом вынести отдельным продуктом без раскопок, а не заводить продукт сейчас.

## Границы зоны

- **что решает шлюз** — как один ресурс достаёт до другого: адрес, доступ, канал;
- **чего он не решает** — что такое ресурс и место в мире (`WORLD2` 2.5, `2.0`), кто кому даёт доступ по правилам мира (`WORLD2` 1.3), сколько на ресурсе памяти и ядер (это отдельный инструмент осмотра).

**VPN — лишь один из вариантов.** Начинаем с простого; выбор средства принадлежит этой зоне и записывается в раздел `TECH` на стенде.

## Где что лежит

| | где |
|---|---|
| правила мира, которым шлюз обязан подчиняться | раздел `WORLD2` на стенде Windshift |
| решения по реализации: чем и как связываем | раздел `TECH` там же |
| работа и её состояние | задачи в `WORLD2` (роадмап итераций) |
